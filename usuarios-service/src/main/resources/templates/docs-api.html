Cómo probar endpoints protegidos

  1. En el servicio usuarios-service, ejecute POST /api/auth/login con su usuario y contraseña.
  2. Copie el valor de token de la respuesta.
  3. Pulse Authorize, pegue el token (sin el prefijo Bearer) y confirme.
  4. Las operaciones respetan los permisos de su rol: si no los tiene recibirá 403.
